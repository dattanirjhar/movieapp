# Movie App 🎬

A simple and responsive movie application built with React.js that allows users to search for movies and save them as favorites. 
This project is deployed using GitHub Pages.

## ✨ Features

  * **Search for movies:** Easily search for any movie by its title.
  * **Favorites:** Save your favorite movies by clicking the heart button on the movie card. You can view favorites on the Favorites page.
  * **Responsive design:** The app is designed to work seamlessly on both desktop and mobile devices.

-----

## 🛠️ Built With

  * [React.js](https://reactjs.org/) - A JavaScript library for building user interfaces.
  * [Vite](https://vitejs.dev/) - A fast build tool that provides a quicker and leaner development experience for modern web projects.
  * [TMDB API](https://www.themoviedb.org/documentation/api) - The Movie Database (TMDB) is a community-built movie and TV database.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js and npm installed on your machine.

  * npm
    ```sh
    npm install npm@latest -g
    ```

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/your-username/your-repo-name.git
    ```
2.  Install NPM packages
    ```sh
    npm install
    ```
3.  Get a free API Key at [https://www.themoviedb.org/signup](https://www.themoviedb.org/signup) (or from your chosen API provider).
4.  Enter your API in `src/App.jsx` (or your relevant component file).

-----

## Usage

To run the app in the development mode:

```sh
npm run dev
```

Open [http://localhost:5173](https://www.google.com/search?q=http://localhost:5173) to view it in the browser.

To build the app for production:

```sh
npm run build
```
